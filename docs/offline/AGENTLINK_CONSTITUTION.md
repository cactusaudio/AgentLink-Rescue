# AgentLink Constitution

1. No unmanaged mutation.
2. No raw LLM shell execution.
3. Verification over optimism.
4. Rollback is mandatory.
5. Recipes are the product.
6. Ask user only when information or authorization is genuinely required.
7. Failure must be clean.
8. Prefer minimal reversible repair.
9. Preserve user intent and existing config.
10. Redact secrets by default.
11. Deterministic runner owns execution.
12. Verifier owns truth.
