### P2 backlog (do not block v0.5.1)

1. **`scripts/release_check_chaos.sh:18` BIN path mismatch.** The script sets `BIN="$ROOT/dist/Cactus-AgentLink-Rescue/bin/agentlink"` and falls back to `scripts/build.sh` if BIN is missing. But `build.sh` writes to `$ROOT/bin/agentlink`, not the dist path. Result: clean-checkout invocations fail with *"No such file or directory"* between build and execution. Workaround: run `scripts/package.sh` first. **Fix:** change BIN to `$ROOT/bin/agentlink`, OR call `scripts/package.sh` instead of `scripts/build.sh`. ~3 line change.

2. **Chaos fixture coverage is thin.** Only 3 fixtures, all under `testdata/chaos/network/`. Codex's claim *"fixtures cover package/network/rollback/installer/gui categories"* is over-stated. Add fixtures for the other 4 categories before claiming broad chaos coverage. The `chaos.go` runner can already classify against those — only the JSON fixtures need adding.

### P3 backlog

3. **`agentlink journal recover --dry-run` prints usage but exits 0.** The CLI uses `--yes` (not `--dry-run`) to switch from analyze-mode to commit-mode; an unknown `--dry-run` flag is reported as *"flag provided but not defined: -dry-run"* and the script exits 0 with empty stdout. Cosmetic — the safer default (analyze) still applies. Either accept `--dry-run` as a no-op alias or exit non-zero.
