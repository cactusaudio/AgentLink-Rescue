# Clash Verge Rev Source

AgentLink uses the official Clash Verge Rev GitHub releases only:

https://github.com/clash-verge-rev/clash-verge-rev/releases

The cached DMG is optional and ignored by git. Fetch it with:

```bash
scripts/fetch_clash_verge_rev.sh
```

AgentLink does not import proxy profiles, enable system proxy, enable TUN, or launch Clash Verge Rev automatically.
