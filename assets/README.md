# AgentLink Brain Assets

This directory holds manifests, local model/runtime assets, and license files for the optional v0.3 Brain Pack.

- `assets/models/` is intentionally ignored for GGUF files.
- `assets/runtimes/llama.cpp/` is intentionally ignored for downloaded llama.cpp binaries.
- `assets/manifests/` and `assets/licenses/` are committed.

Core packages do not include the Qwen GGUF or llama.cpp runtime. Brain packages may include both assets in `dist/`.
